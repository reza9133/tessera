# Tessera (تسِرا)

**قراردادهایی که به زبان ساده نوشته می‌شن و با اجماع ولیدیتورها تسویه می‌شن.** ساخته‌شده برای شبکه‌ی Studionet جن‌لایر.

در روم باستان «تسرا» لوحی بود که می‌شکوندنش؛ هر طرف نیمی رو نگه می‌داشت و وقتی دو نیمه دقیقاً جفت می‌شد، قرارداد اثبات می‌شد. این پروژه همون ایده است برای کارهایی که روی اینترنت انجام می‌شن:

1. **سازنده‌ی پیمان** شرایط رو به زبان ساده می‌نویسه، چند معیار (rubric) تعریف می‌کنه و مبلغ رو در escrow قفل می‌کنه.
2. **تحویل‌دهنده** پیمان رو می‌پذیره و لینک‌های عمومی رو به‌عنوان شواهد ثبت می‌کنه.
3. موقع درخواست جلسه‌ی رسیدگی، **پنج ولیدیتور هرکدوم خودشون شواهد رو دریافت و بررسی می‌کنن**.
4. پول طبق حکم جابه‌جا می‌شه: کامل، متناسب با وزن معیارهای برآورده‌شده، یا برگشت به سازنده. یک بار می‌شه اعتراض کرد و جلسه‌ی دوم قطعی است.

قرارداد **مالک، کلید ادمین و قابلیت ارتقا نداره**. پول فقط طبق قوانین `contracts/tessera.py` حرکت می‌کنه.

> اجماع مدل‌ها یک رویه‌ی قابل‌تکرار است، نه دادگاه، و هیچ‌چیز اینجا مشاوره‌ی حقوقی نیست. Studionet شبکه‌ی آزمایشی است و GEN ارزشی نداره.

## راه‌اندازی در پنج گام

### ۰. تست محلی (اختیاری)
```bash
npm install
npm test          # ۱۲۹ تست قرارداد + آینه‌ی جاوااسکریپت روی بیش از ۸۰۰ بردار
npm run mutate    # ۶۶ باگ عمدی؛ همه باید توسط تست‌ها گرفته بشن
```

### ۱. قرارداد رو روی Studionet مستقر کن
**روش الف (از مرورگر):** برو به <https://studio.genlayer.com>، یک قرارداد جدید بساز، محتوای `contracts/tessera.py` رو paste کن، شبکه‌ی *Studionet* رو انتخاب کن و Deploy بزن (قرارداد آرگومان سازنده نداره). آدرس قرارداد رو کپی کن.

**روش ب (از ترمینال):**
```bash
npm run deploy:contract
```
این دستور با یک کلید موقت قرارداد رو مستقر می‌کنه و آدرس رو توی `wrangler.toml` می‌نویسه.

> **نکته‌ی رانر:** خط اول قرارداد `py-genlayer:1jb45aa8…` است که رانرِ Studionet پایدار (chain 61999) هست. Studio-dev (chain 61997) رانر و import متفاوتی داره و این قرارداد عمداً برای اون نوشته نشده. اگه Studio گفت رانر نامعتبره، خط اول رو از یکی از قراردادهای نمونه‌ی خود Studio کپی کن.

### ۲. آدرس قرارداد رو تنظیم کن
فایل `wrangler.toml` رو باز کن و مقدار `CONTRACT_ADDRESS = "0x…"` رو بذار.

### ۳. سایت رو روی Cloudflare Pages مستقر کن
```bash
npx wrangler login
npx wrangler pages deploy        # بار اول پروژه‌ی «tessera» رو می‌سازه
```
یا ریپو رو از داشبورد Cloudflare وصل کن با: **Build command: خالی**، **Output directory: `public`**. پوشه‌ی `functions/` خودکار شناسایی می‌شه.

تا وقتی `CONTRACT_ADDRESS` خالیه، سایت در **حالت سندباکس** باز می‌شه: کل محصول داخل مرورگر و با همون قوانین اجرا می‌شه، با یک قاضیِ کلیدواژه‌ای به‌جای ولیدیتورها. هر حکم سندباکس صراحتاً همین رو می‌گه.

### ۴. روی شبکه‌ی واقعی امتحانش کن
```bash
CONTRACT=0x… SITE=https://your-site.pages.dev npm run smoke
```
دو حساب تازه یک پیمان کامل رو اجرا می‌کنن (ایجاد، پذیرش، تحویل، جلسه‌ی واقعی رسیدگی، تسویه). چند دقیقه طول می‌کشه.

### ۵. سناریوها رو امتحان کن
توی صفحه‌ی اصلی چهار سناریو هست (تحویل تمیز، پیش‌نویس کوتاه، لینک مرده، حمله‌ی تزریق). هر کدوم یک پیمان با همون شرایط می‌سازه و صفحه‌ی شواهد آماده‌اش روی همین دامنه‌ی تو سرو می‌شه تا ولیدیتورها بخوننش.

> قرارداد (و سندباکس) لینک‌های `localhost` رو رد می‌کنن؛ پس سناریوها فقط روی دامنه‌ی عمومی کار می‌کنن. اول یک نسخه‌ی preview مستقر کن.

## چیزهایی که راستی‌آزمایی شده و نشده

**راستی‌آزمایی شده (در محیط ساخت):** منطق قرارداد (۱۲۹ تست؛ ۶۶ از ۶۶ جهش گرفته شد)، یکسان‌بودن حساب‌وکتاب UI با قرارداد (بیش از ۷۰۰ بردار طلایی)، کل رابط کاربری در Chromium (دسکتاپ، موبایل، تم تیره و روشن) با چهار سناریو، و تابع `/api/config`.

**راستی‌آزمایی نشده** (محیط ساخت به شبکه دسترسی نداشت): اجرا زیر GenVM واقعی و مدل‌های ولیدیتورهای واقعی؛ فراخوانی‌های `genlayer-js@1.1.8` روی Studionet (از جمله پیش‌نمایش رایگان با `simulateWriteContract`)؛ جریان MetaMask؛ نام RPC شیر آب (faucet)؛ شکل آدرس‌های explorer؛ و CSP روی esm.sh. برای همه‌ی این‌ها `npm run smoke` رو اجرا کن و بار اول کنسول مرورگر رو نگاه کن.

## عیب‌یابی سریع
- **بعد از استقرار هنوز «Sandbox» نشون می‌ده:** `CONTRACT_ADDRESS` خالیه یا آدرس ۴۲‌کاراکتری معتبر نیست. آدرس `/api/config` رو چک کن.
- **بنر می‌گه Studionet جواب نداد:** RPC یا esm.sh در دسترس نبود؛ دکمه‌ی *Retry Studionet* رو بزن.
- **جلسه‌ی رسیدگی «تموم شد ولی چیزی عوض نشد»:** ولیدیتورها توافق نکردن یا قاضی خطا داد؛ قبل از اجماع هیچ وضعیتی نوشته نمی‌شه، پس چیزی از دست نرفته. دوباره امتحان کن.
